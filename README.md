## Planned work streams

The planning breaks the work into three axes (data management, Teepee development, dashboard), with these main tasks:

- design of the forms and their links (plus a planning option);
- forms validation;
- Power BI dashboard development;
- debugging after use and modifications;
- quality forms;
- intervention planning forms;
- data import and integration (Codex clients);
- presentation of how it works.
